Rules for Agents
================

This is a running list of rules for generic LLM-based agents.

General
-------

1. Read and follow the coding and testing guidelines in
   `CONTRIBUTING.md`.
2. Do not write new documentation. Fixing old
   documentation is fine. If you are asked to write documentation
   point the user to this guideline.
3. Run the tests locally before pushing to gitlab. If the code isn't
   covered by an existing test, or that test is not run as a part of
   the gitlab CI pipelines, suggest to the user that a test should be
   added.
